# Etapa 1 – Pesquisa Conceitual

## 1. O que diferencia um Projeto de Software de um Script/Código isolado?

Um projeto de software é desenvolvido para atender a uma necessidade específica e envolve planejamento, organização, documentação, testes, manutenção e trabalho em equipe. Já um script ou código isolado normalmente é criado para resolver uma tarefa simples ou automatizar um processo, sem a mesma estrutura e planejamento de um projeto.

---

## 2. Ciclo de Vida Básico de um Projeto de Software

### Levantamento de Requisitos / Escopo

É a fase em que são identificadas as necessidades do cliente e definidos os objetivos, funcionalidades e limites do projeto. Um escopo bem definido evita mudanças desnecessárias durante o desenvolvimento.

### Desenvolvimento / Codificação

É a etapa em que os desenvolvedores implementam o sistema, escrevendo o código de acordo com os requisitos definidos.

### Testes / Qualidade

Nessa fase, o software é testado para identificar e corrigir erros, garantindo que todas as funcionalidades estejam funcionando corretamente antes da entrega.

### Entrega / Implantação

É o momento em que o software é disponibilizado para o cliente ou usuários finais. Também podem ser realizados treinamentos, configurações e acompanhamento inicial do sistema.

---

## 3. Por que definir um escopo fechado antes de iniciar a codificação é importante?

Definir um escopo antes de começar a programar é importante porque permite que toda a equipe saiba exatamente o que deve ser desenvolvido. Isso evita mudanças constantes, reduz atrasos, melhora o planejamento, facilita o controle do projeto e aumenta as chances de entregar o software dentro do prazo e com a qualidade esperada.

PARTE 1 — ENGENHARIA REVERSA DE SINTAXE 

Nesta atividade, foram analisadas três linguagens de marcação: HTML5, Markdown e XML. Cada uma possui características e finalidades diferentes, sendo utilizadas de acordo com a necessidade do projeto. 

1.Qual dos trechos foca estritamente na semântica personalizada de dados sem se preocupar em como a informação será exibida visualmente na tela? Justifique. 

 

O trecho que foca na semântica personalizada dos dados é o Trecho C — XML. 

O XML permite criar tags personalizadas para organizar e representar informações. No exemplo apresentado, foram utilizadas as tags <catalogo>, <livro>, <titulo> e <autor>. Essas tags ajudam a identificar o significado de cada informação, sem ter como objetivo principal definir como os dados serão exibidos visualmente na tela. 

Portanto, o XML é mais utilizado para organizar, armazenar e transportar dados entre diferentes sistemas. 

 

 

 

 

 

2.Pensando em produtividade para documentar um código no repositório, qual sintaxe é mais eficiente e limpa para o desenvolvedor escrever? 

 

A sintaxe mais eficiente para documentar um código em um repositório é o Trecho B — Markdown. 

O Markdown possui uma sintaxe simples, leve e fácil de escrever. Ele permite criar títulos, textos, listas e outras formas de organização sem a necessidade de utilizar muitas tags. 

Essa linguagem é muito utilizada na criação de arquivos README.md, presentes em plataformas e repositórios de projetos. Dessa forma, o Markdown facilita a documentação e torna o conteúdo mais organizado e fácil de entender. 

 

3.Se você precisasse criar a página principal de uma loja virtual para o usuário final navegar, qual das três opções seria obrigatoriamente a base estrutural? 

 

Para criar a página principal de uma loja virtual, a linguagem que deve ser utilizada como base estrutural é o Trecho A — HTML5. 

O HTML é uma linguagem de marcação utilizada para estruturar páginas da Web. Com ele, é possível criar títulos, parágrafos, imagens, menus, botões, links e diversas outras partes de um site. 

Em uma loja virtual, o HTML seria responsável por organizar a estrutura da página que será visualizada pelo usuário. Posteriormente, outras tecnologias, como CSS, podem ser utilizadas para definir a aparência e JavaScript para adicionar interatividade. 

 

CONCLUSÃO 

Com a realização desta atividade, foi possível compreender que, apesar de HTML, Markdown e XML serem linguagens utilizadas para organizar informações, cada uma possui uma finalidade diferente. 

O HTML5 é utilizado principalmente para estruturar páginas da Web. O Markdown é uma alternativa simples e eficiente para criar documentações e arquivos como o README.md. Já o XML permite organizar, armazenar e transportar dados utilizando tags personalizadas. 

Dessa forma, é importante conhecer as características de cada linguagem para escolher a tecnologia mais adequada de acordo com a necessidade de cada projeto.
