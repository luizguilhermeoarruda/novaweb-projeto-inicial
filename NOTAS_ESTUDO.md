# Etapa 1 – Pesquisa Conceitual

## 1. O que diferencia um Projeto de Software de um Script/Código isolado?

Um projeto de software é desenvolvido para atender a uma necessidade específica e envolve planejamento, organização, documentação, testes, manutenção e trabalho em equipe. Já um script ou código isolado normalmente é criado para resolver uma tarefa simples ou automatizar um processo, sem a mesma estrutura e planejamento de um projeto.

---

## 2. Ciclo de Vida Básico de um Projeto de Software

### Levantamento de Requisitos / Escopo

É a fase em que são identificadas as necessidades do cliente e definidos os objetivos, funcionalidades e limites do projeto. Um escopo bem definido evita mudanças desnecessárias durante o desenvolvimento.

### Desenvolvimento / Codificação

É a etapa em que os desenvolvedores implementam o sistema, escrevendo o código de acordo com os requisitos definidos.

### Testes / Qualidade

Nessa fase, o software é testado para identificar e corrigir erros, garantindo que todas as funcionalidades estejam funcionando corretamente antes da entrega.

### Entrega / Implantação

É o momento em que o software é disponibilizado para o cliente ou usuários finais. Também podem ser realizados treinamentos, configurações e acompanhamento inicial do sistema.

---

## 3. Por que definir um escopo fechado antes de iniciar a codificação é importante?

Definir um escopo antes de começar a programar é importante porque permite que toda a equipe saiba exatamente o que deve ser desenvolvido. Isso evita mudanças constantes, reduz atrasos, melhora o planejamento, facilita o controle do projeto e aumenta as chances de entregar o software dentro do prazo e com a qualidade esperada.
