# Guia de Estilo Inicial — Loja Virtual

## 1. Regra 60-30-10

A regra 60-30-10 é uma técnica utilizada para organizar as cores de uma interface, criando equilíbrio visual e facilitando a experiência do usuário.

* **60% — Cor dominante:** utilizada principalmente em fundos e áreas maiores.
* **30% — Cor secundária:** utilizada em menus, cabeçalhos, textos e elementos estruturais.
* **10% — Cor de destaque:** utilizada em botões, preços e elementos importantes que precisam chamar a atenção.

## 2. Paleta de Cores

### 60% — Branco

**HEX:** `#FFFFFF`

Utilizado principalmente no fundo das páginas da loja.

### 30% — Preto

**HEX:** `#111111`

Utilizado no cabeçalho, textos, menus e outros elementos estruturais.

### 10% — Dourado

**HEX:** `#D4AF37`

Utilizado nos botões, preços e elementos de destaque.

### Justificativa

A combinação de branco, preto e dourado foi escolhida para criar uma aparência moderna, elegante e organizada. O branco mantém a interface limpa, o preto proporciona contraste e o dourado chama a atenção para os elementos mais importantes.

## 3. Tipografia

### Títulos — Poppins

A fonte Poppins foi escolhida para os títulos por apresentar um estilo moderno e facilitar a criação de uma hierarquia visual.

### Textos — Inter

A fonte Inter foi escolhida para os textos por ser simples, limpa e apresentar boa legibilidade.

## 4. Aplicação no Projeto

As cores e fontes serão utilizadas em toda a interface da loja, mantendo um padrão visual entre o cabeçalho, menus, produtos, botões e demais elementos.

## 5. Objetivo

O objetivo da identidade visual é criar uma loja virtual com aparência moderna, organizada e fácil de utilizar, proporcionando uma boa experiência para o usuário.
